# Documentação do projeto

Esta pasta reúne o contexto necessário para agentes trabalharem no funil de triagem da Dra. Ana Maria de Magalhães.

## Documentos

- `manychat-context.md`: resumo executivo, arquitetura, integrações, estado atual e pendências.
- `manychat-flow-spec.md`: especificação operacional do fluxo de triagem e das regras de qualificação.

Para uma tarefa no ManyChat, leia primeiro o contexto e depois a seção correspondente da especificação. Para uma tarefa no quiz ou n8n, consulte também `CHECKLIST.md`, o código e os testes.

## Regra de precedência

Decisões confirmadas pela cliente prevalecem sobre hipóteses do código, rascunhos ou sugestões. Quando uma decisão ainda estiver aberta, o item deve permanecer marcado como `PENDENTE DE CONFIRMAÇÃO`.
